# Using This Repository

Each `Qn/README.md` includes:

* The exact commands that were executed.
* The corresponding output generated by those commands.
* A short explanation describing what each command does and the observed result.
* A justification section explaining the Linux concepts, commands, redirection operators, or system calls used in the solution.

The `screenshots/` directory within each question contains terminal screenshots supporting the documented commands and outputs.

* For **Q1–Q4**, the screenshots correspond to commands that were actually executed and whose outputs are included in the repository.
* For **Q5**, since the task is a conceptual evaluation rather than an executable program, the screenshots illustrate the standard Vim recovery process (`vi -r`, the **E325: ATTENTION** prompt, and the recovery workflow) to support the written explanation.

> **Note:** If your instructor requires screenshots captured directly from your own Linux system or virtual machine, simply execute the commands listed in each README and replace the existing images with your own screenshots.

# Testing Notes

All scripts and programs were tested before being included in this repository. Running the programs helped identify and fix a few implementation issues, which are also documented in the respective README files.

### Question 1

The initial version of the duplicate-detection script relied on:

```bash
[ -f "$file" ]
```

This caused broken symbolic links to be skipped completely instead of being reported as invalid submissions. The script was updated to detect and log unreadable files explicitly, ensuring that every submission is accounted for.

### Question 2

During testing, the process manager produced duplicate output when standard output was redirected to a file. This occurred because of standard I/O buffering after `fork()`.

The issue was resolved by enabling line-buffered output using:

```c
setvbuf(stdout, NULL, _IOLBF, 0);
```

Further details about these fixes are provided in the README files for **Q1** and **Q2**.
